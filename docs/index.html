COMO VOCÊ QUER GERAR?

Recomendado: prepare o kit aqui e use seus créditos existentes no Google Flow. A geração é confirmada no site do Google, sem usar a API paga do Observatório.

Duração solicitada pelo roteiro (~8 s), proporção 9:16. A duração real pode variar. Os preços da API variam e podem ser cobrados pelo Google. Verifique faturamento e disponibilidade do modelo antes de gerar.

PASSO 3 · PUBLICAÇÃO

Como usar no celular

1Selecione uma ofertaConfira o valor, a imagem e a URL do produto.
2Copie o prompt VeoNo Google Flow, selecione Veo e use a imagem como referência.
3Publique o conteúdoA legenda terá o link da própria publicação e pedirá “Comente EU QUERO”.
4Associe à sua DMConfigure o ID do post, o produto e o link correto no seu sistema de automação.

Observação: links em legendas do Instagram podem não ser clicáveis; a DM permite disponibilizar o link de forma mais prática. O pacote não publica nem envia mensagens sozinho. Preços são referentes às capturas e precisam ser verificados antes de postar.
